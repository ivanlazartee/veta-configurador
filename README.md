# Veta — Configurador de mesas a medida

Proyecto demo de **NorteDigitalDev**. Veta es una marca ficticia.

El cliente arma su mesa (madera, medidas, terminación y patas), ve el plano y el precio en vivo, y envía el pedido por WhatsApp.

## Tecnologías

- HTML, CSS y JavaScript puro (sin dependencias)
- SVG generado con JS para el plano
- Tipografía: Archivo (Google Fonts)

## Cómo verlo

Abrí `index.html` en el navegador, o usá la extensión **Live Server** de VS Code.

## Estructura

```
index.html
css/styles.css
js/app.js
```
